# Source provenance

The `pyslopeunits/` Python sources in this release tree were reconstructed directly from the PySlopeUnits **0.1.8** wheel used for the manuscript benchmark. Generated byte-code caches were excluded.

The repository test suite should be preserved when this release tree is copied over an existing Git working tree. `tests/test_release_v018.py` is an additional lightweight smoke test and does not replace the existing regression tests.

The principal v0.1.8 code change relative to v0.1.7 concerns adaptive handling and persistence of the MFD accumulation working set in `mfd_parallel.py` and the associated initialization kernels in `kernels.py`.
